# いけの ボール タッチ！

池に浮かんだボールを、30 秒のあいだに何回タッチできるかを競う、小学生向けの反射神経ゲームです。
1 回 100 円で遊ぶゲーム台を想定しています。

**あそぶ:** https://tsubasagit.github.io/reflex-ball/

## あそびかた

1. 100 えん硬貨を指でつまんで、「いれぐち」までひっぱって入れる
2. 「スタート」を押すと 3・2・1 のカウントダウン。終わった瞬間にボールが動き出す
3. 30 秒のあいだに、ボールをたくさんタッチ！
4. つづけてタッチするとコンボで得点アップ（×2〜×4）
5. 金のボールは 500 てん、カエルは 300 てん
6. さいごの 10 秒は得点 2 ばい

終わると点数・称号（おたまじゃくし〜りゅうじん）・チケット枚数が出て、5 位までならランキングに名前を残せます。

## とくちょう

- 池を真上から見た水面を WebGL で描画（水底の小石、屈折、揺れる光の網、空と岸の木の映り込み）
- 水面の高さを計算して、ボールの航跡・タッチの波紋・壁での跳ね返りを再現
- 金のボール・カエル・雨のイベントが毎回ちがうタイミングで起きる
- 蓮の葉は指で押すと流れて回る
- 効果音はその場で合成（音声ファイルなし）
- HTML 1 枚で完結。ライブラリ・ビルド不要

## 動かし方

`index.html` をブラウザで開くだけで遊べます。ローカルサーバーで開く場合は:

```bash
python -m http.server 8997
```

ブラウザで http://localhost:8997 を開きます。

## お店の人むけ

- キーボードの `C` でコイン（クレジット +1）
- ランキングの「けす」で記録を消去（記録はその端末のブラウザの中だけに残ります）
- 画面下の「おと」で効果音のオン/オフ

## ご注意

- 100 えん硬貨は画面上の模擬です。実際のお金のやりとりや、硬貨投入機・チケット払い出し機との接続はありません
- WebGL が使えない環境では、簡易表示で遊べます
